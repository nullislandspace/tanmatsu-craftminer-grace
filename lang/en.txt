# SynthMiner -- English, and the list of every string the UI can show.
#
# THIS FILE DEFINES THE KEYS. `tools/make_lang.py` turns the keys here into
# the SM_STR_* enum the code uses, so a key that is not here does not exist,
# and every other language is checked against this one: a key it lacks falls
# back to the English below, and a key it invents is an error.
#
# Format: `key = text`, one per line, UTF-8, `#` starts a comment. Leading and
# trailing spaces around the text are dropped -- put \s at either end if you
# need one. \n is a line break, \\ a backslash.
#
# A %-placeholder is filled in by the game and MUST survive translation: the
# SAME ONES, IN THE SAME ORDER. They cannot be reordered -- the badge's printf
# is not promised to understand %1$s -- so a line needing another word order
# needs the English changed too, not the translation bent around it. What each
# placeholder holds is in the comment above its line, and `make check` fails on
# any translation whose placeholders differ from this file's.
#
# NOT translated, on purpose: the name SynthMiner; world names, which the
# player types; key names like Esc and Left Shift, which are what is printed
# on the badge's keys; and every log message, which is for us.
